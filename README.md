# เงินดี (NgernDee)

เว็บแอปผู้ช่วยดูแลบัญชีส่วนบุคคลภาษาไทย สำหรับสรุปรายรับ–รายจ่าย บัญชี บัตรเครดิต หนี้ งบประมาณ เงินออม การลงทุน และภาษี

## ความสามารถปัจจุบัน

- แดชบอร์ดการเงินที่รองรับคอมพิวเตอร์และมือถือ
- หน้ารายละเอียดครบทุกเมนู
- เพิ่มรายการรายรับและรายจ่าย
- นำเข้า Statement จาก Excel, CSV และ TSV
- ตรวจคอลัมน์เงินเข้า–ออกและรายการซ้ำเบื้องต้น
- อ่านรูปสลิปภาษาไทย/อังกฤษบนอุปกรณ์ด้วย OCR
- PWA และระบบซิงก์บัญชีผู้ใช้เป็นงานลำดับถัดไป

ข้อมูลตัวเลขที่มากับหน้าจอเป็นข้อมูลตัวอย่าง ไม่ใช่ข้อมูลการเงินจริง

## เริ่มใช้งานสำหรับนักพัฒนา

ต้องใช้ Node.js 22.13 ขึ้นไป จากนั้นรัน npm install และ npm run dev แล้วเปิด http://localhost:5173

ตรวจสอบงานด้วย npm run lint และ npm run build

## ความปลอดภัย

- ห้าม commit ไฟล์ .env หรือคีย์ลับ
- รูปสลิปประมวลผลบนอุปกรณ์และต้องให้ผู้ใช้ยืนยันก่อนบันทึก
- Statement และข้อมูลส่วนบุคคลจริงต้องไม่อยู่ใน repository
- การใช้งานจริงควรเปิดฐานข้อมูลที่เข้ารหัส การยืนยันอีเมล และนโยบายสำรองข้อมูล

## สถานะ

ส่วนติดต่อและการนำเข้าข้อมูลอยู่ในระยะ MVP ระบบสมาชิก คลาวด์ซิงก์ PWA และไฟล์ติดตั้ง Windows ยังต้องเชื่อมบริการจริงก่อนเผยแพร่ใช้งาน
